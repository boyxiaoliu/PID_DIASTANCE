# 2026-10-21 饱和/丢失步长调整（用户"多次少量"意见落地）

日期：2026-10-21 ｜ 归属：线B（configs control.loop 节）｜ 状态：**仿真验证通过（重复性档全网格）**

## 一句话结论

按用户意见把"太近退 0.10m / 丢失退 0.20m"改为"太近退 0.03m / 丢失退 0.05m"，
连动放大两个次数上限（max_backoff 5→15、max_iters 20→40）后，
重复性档 12,600 次全网格最低收敛率 **100%**（原参数 99.5/99.5/99.0），
方向性违规 0。代价：深起点逃生时间约翻倍。

## 改动（前后对比）

| 参数 | 前 | 后 | 起因 |
|---|---|---|---|
| `sat_step_m` | 0.10 | **0.03** | 用户意见"多次少量"：饱和=看得见但太近，小步细退更稳 |
| `backoff_m` | 0.20 | **0.05** | 同上（丢失=黄蓝全无的盲退） |
| `max_backoff` | 5 | **15** | 连动：0.05×5=0.25m 预算不足——d\*=1.8 档丢失区宽 0.53m |
| `max_iters` | 20 | **40** | 连动：小步逃生+贴近轮数约翻倍（深起点实测 22 轮） |

## 第一版教训（0.03/0.05/12/20 → 未过）

只改步长、次数上限连动不足：12,600 次全网格最低收敛率 **42.5%**
（93 例 lost 放弃 + 240 例 max_iters 耗尽，集中在 d\*=1.8 深起点）。
教训：**步长缩小 N 倍，"次数型"参数必须按逃生几何连动重算**，
否则等于变相削减了逃跑预算。

## 第二版结果（0.03/0.05/15/40 → 通过）

- 重复性档（σ=0.005 × 1/2/3，7 距离 × 3 档 d\* × 200 种子 = 12,600 次）：
  最低收敛率 1×=**100.0%**、3×=**100.0%**（及格线 99/95），方向性违规 **0**，
  合法起点越线 1 起（与原参数持平，浅越线自愈）
- 应力档 quick 冒烟：1×=100%、3×=80%——"应力档数学上不可满足"的结论不变，
  **真机 σ 实测仍是上车门禁**
- 最深逃生单点（d\*=1.8，d0=0.9，3× 噪声）：22 轮收敛 ✓

## 代价与残留（如实）

1. **深起点逃生时间翻倍**：d\*=1.8 从 0.9m 约 22 轮 ≈ 110s（真机 5s/轮）；
   常规起点（贴近 d\*）不受影响，约 8 轮
2. "已越线又更近 77 起"为小步+停稳噪声的浅凹陷（min_d 0.872m，发生在
   本就低于安全线的深起点），非前进指令所致；方向性违规仍为 0
3. `sat_step_m=0.03` 与 `sim.move_std=0.02` 同量级：约 7% 的饱和小步被停稳
   噪声吃掉（多花一轮，无害）。真机 move_std 实测后需复核此步长
