## 一、目的（一句话）

上真机前的安全网 + 调参的证据机器：证明"读数 → 位移指令"这套控制器
（真机要跑的那份代码）在 0.9~3.4 米任意起点、含噪声和坏帧的情况下收敛，
且**任何情况下不朝书架越线逼近**。

## 二、架构（三件套）

```
src/pid_servo/servo.py      控制器（从 旧PID控距/src/pid_servo/servo.py 移植改造）
src/pid_servo/shelf_sim.py  合成书架后端（observe/move 注入接口，同真机适配层形状）
tools/sim_servo.py          网格跑批 + metrics 输出
tests/test_servo.py         PID/状态机单元测试（移植改造）
```

注入式约定（旧项目已验证的设计）：控制器只调 `observe() -> Observation` 和
`move(delta_m)`，不知道对面是合成书架还是真车。**仿真跑的代码 = 上车跑的代码。**

### servo.py 移植改造清单

| 旧项目原有 | 新项目处理 |
|---|---|
| PID（死区/微分低通/抗饱和/增益调度） | 原样移植；kp 按 新误差灵敏度 重推（见下） |
| DistanceServo 状态机（hold_frames 中值收敛判据、backoff） | 原样移植 |
| 观测契约 span_frac | 换 bar_frac；**新增饱和规则**（见实验 README 标度表）：间距<gap_min 或 蓝线≥0.95 未检出 → 读数按 1.0 → 后退；丢失 → 固定步后退 max_backoff 次 |
| SyntheticShelf f=k/d | 换 shelf_sim 的 A+B/d（见下） |

kp 量纲重推：读数(d)=A+B/d → |∂读数/∂d| = B/d*²，d*=1.5、B=(0.955−0.5)×1.5=0.68
→ 灵敏度 ≈ 0.30/m → kp 初值 ≈ 1/0.30 ≈ 3.3（configs 里现为 3.70，以仿真调优为准）。

## 三、合成书架模型（shelf_sim）

- **读数模型**：`reading(d) = A + B/d*`系。A=0.50（d→∞ 时横杆趋于画面中心的地平线）；
  B = (target − A)·d*，使完美距离 d* 处读数恰为 target
- **d* 不确定**：真值未知，按 {1.2, 1.5, 1.8} 三档全跑——控制器对 d* 误设应稳健
- **观测噪声**：真值不可测（每点只拍过一次），用旧项目同货架实测 σ=0.0299 作基准，
  按 1×/2×/3× 三档压力测试。3 倍仍收敛才算稳
- **执行模型**：`move(δ)` → d += δ + N(0, 0.02)（底盘停稳散布，假设值）
- **坏帧注入**：每轮 2.4% 概率丢失（真数据比例 6/247）；饱和态按标度表判
- **时间成本估算**：每轮 = 移动+停稳+拍照 ≈ 5s，仿真同时输出预计 wall-time

## 四、考试网格

| 维度 | 取值 |
|---|---|
| 初始距离 d0 | 0.9, 1.2, 1.5, 2.0, 2.5, 3.0, 3.4（米） |
| 噪声档 | 1×, 2×, 3×（σ₀=0.0299） |
| d* 档 | 1.2, 1.5, 1.8 |
| 种子 | 每格 200 个（固定种子可复现） |

合计 7×3×3×200 ≈ **12,600 次闭环**（纯数学，几分钟跑完）。

### 及格线

- 标称噪声收敛率 ≥99%，3× 噪声 ≥95%
- **安全线：全程 d ≥ d* − 0.15**，且饱和/丢失后绝不产生前进指令（方向性检查）
- 每格记录：收敛率、轮数分布、min(d)、违反方向性的次数（必须为 0）

## 六、仿真证明不了什么（必须与结果一起呈现）

- 不验证感知（已在 153 张真图 + 用户目检闭环）
- 不验证底盘停稳精度、补光、对焦、震动 → S5 真机是最终关卡
- 结论单向有效：仿真不过 = 必不过；仿真过了 = 有资格上车
